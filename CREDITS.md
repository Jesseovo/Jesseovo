# Credits and maintenance

- Profile layout takes inspiration from [hicccc77](https://github.com/hicccc77).
- The full-body pixel cat is redrawn from the meme sheet supplied by the profile
  owner with six flat colors, in a perler-bead style. Its original idle drawing
  sits on a 36 by 36 grid with extra transparent room for its paws.
  `scripts/animate_cat.py` draws `assets/pixel-cat.png`, the compact animated
  `assets/pixel-cat.gif`, and the 320 by 80 transparent title strip
  `assets/pixel-cat-walk.gif` with Pillow. The cat walks back and forth, pausing
  to blink, wave, tilt its head, stretch and hop. Alternate poses are drawn
  cell by cell; movement uses integer coordinates without rotation or warping.
  The GIF works in a GitHub README without page scripts or custom CSS.
- Contribution snakes are generated by [Platane/snk](https://github.com/Platane/snk).
- The typing animation, project and contact cards, and small pixel still life are maintained in
  `scripts/build_artwork.py`.
  Project descriptions summarize each repository's public README. The cards
  use compact, transparent pixel computer and open-book illustrations, include
  light and dark variants, and link directly to the corresponding repositories.
  The matching contact cards use original pixel envelope and browser illustrations,
  with shared icon edges, text positions and row spacing. Both rows use a
  208-pixel left column, a 176-pixel right column and the same gap; the shorter
  right canvas removes trailing whitespace to keep the visible content centred.

## Updating the profile

Edit `README.md` for text and project links. To change the typing animation, project cards or pixel still life,
edit `scripts/build_artwork.py` and run:

```sh
python scripts/build_artwork.py
```

To rebuild the cat animation, install Pillow and run `python scripts/animate_cat.py`.
Edit its grid coordinates and palette to change the cat. It does not require
the original reference image or use image warping.

The `Refresh profile artwork` workflow updates the contribution snakes
on the `output` branch daily at approximately 06:30 Asia/Shanghai.
It can also be run manually. It uses the built-in `GITHUB_TOKEN` and needs no
personal access token or additional secrets.
